# Design Brief Template

## Product
Name, type, platform, existing stack.

## Audience
Primary users, expertise, context, accessibility/localization needs.

## Goals
Primary user job, top tasks, success criteria.

## Constraints
Existing components/assets, technical limits, responsive targets, offline/performance needs.

## Design direction
Selected direction, rationale, brand traits, what to avoid.

## Experience architecture
Screens/pages, navigation, primary journey, components, important states.

## Verification
Tests, viewports, visual tools available, known unknowns.
