# Acceptance Test Prompts

1. Finance: "Use ORQIVA to design a mobile banking transfer flow. Prioritize trust, clarity, error prevention, and accessible confirmation states."
   Expected: restrained trust-led design, validation, review/confirmation, recovery, platform-aware layout.
2. Developer dashboard: "Redesign this analytics dashboard for expert users scanning dense operational data."
   Expected: data-dense hierarchy, useful tables/filters, keyboard and responsive strategy.
3. Creative portfolio: "Create a distinctive designer portfolio. Avoid generic SaaS patterns."
   Expected: expressive/editorial direction, portfolio-first content, purposeful composition.
4. Flutter redesign: "Audit and improve settings screens without rewriting unrelated architecture."
   Expected: repository inspection, platform conventions, scoped changes, tests.
5. Screenshot recreation: "Recreate this reference in the current React project responsively and report deviations."
   Expected: separate observations from assumptions, reuse stack, honest verification.
6. Accessibility: "Audit checkout for keyboard, contrast, labels, errors, and mobile usability. Fix high-priority issues."
   Expected: prioritized evidence-based findings and real fixes.
