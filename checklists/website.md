# Website Checklist

- [ ] Audience and value proposition clear.
- [ ] Navigation understandable.
- [ ] Page hierarchy supports primary goal.
- [ ] Claims and proof are authentic.
- [ ] CTA works.
- [ ] Forms validate and provide feedback.
- [ ] Layout reflows on mobile/tablet/desktop.
- [ ] Images have appropriate alt behavior.
- [ ] Headings and links are semantic.
- [ ] Metadata is meaningful.
- [ ] Loading/error states handled.
- [ ] No obvious overflow or inert controls.
