# Mobile UI Checklist

- [ ] Purpose and primary action are clear.
- [ ] Navigation fits destination count and hierarchy.
- [ ] Safe areas/system bars respected.
- [ ] Touch targets usable.
- [ ] Keyboard does not obscure essential controls.
- [ ] Large text/localization do not break layout.
- [ ] Loading, empty, error, success states handled.
- [ ] Permissions requested contextually.
- [ ] Offline behavior clear where relevant.
- [ ] Back navigation correct.
- [ ] Contrast and accessibility reviewed.
