# Responsive Checklist

- [ ] Narrow mobile checked.
- [ ] Typical mobile checked.
- [ ] Tablet/intermediate width checked.
- [ ] Desktop checked.
- [ ] Wide desktop checked where relevant.
- [ ] Navigation adapts.
- [ ] Tables/dense content have a mobile strategy.
- [ ] Text wraps without clipping.
- [ ] Images preserve intended crop/aspect ratio.
- [ ] No unintended horizontal overflow.
- [ ] Touch and pointer controls remain usable.
