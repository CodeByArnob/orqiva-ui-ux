# Adaptive Visual Design Directions

Choose a direction from context, not trend. These are starting points, not rigid templates.

| Product | Likely direction | Priorities | Avoid |
|---|---|---|---|
| Finance | Trust-led, restrained | Clarity, legibility, error prevention | Ambiguous playful UI |
| Healthcare | Calm, reassuring | Accessibility, privacy cues, clear data | Alarmist color, jargon |
| Developer tools | Dense, structured, utilitarian | Scanning, precision, keyboard use | Decorative clutter |
| Creative portfolio | Expressive, editorial | Identity, composition, storytelling | Generic dashboard patterns |
| Ecommerce | Product-led, conversion-aware | Imagery, comparison, trust, checkout | Hidden costs |
| Education | Encouraging, progressive | Learning path, feedback | Excessive gamification |
| Corporate | Confident, editorial | Credibility, clear proposition | Fabricated proof |
| Productivity | Calm, action-oriented | Status, hierarchy, shortcuts | Overloaded panels |
| Media | Typography-led, content-first | Reading rhythm, discovery | UI overpowering content |

Method: identify user job and trust sensitivity; classify task/content/data density; identify interaction mode; choose one primary direction; explain in 2–4 sentences; validate against audience and brand.

Possible languages: minimal utility, editorial, data-dense professional, warm human-centered, premium restrained, expressive creative, platform-native.

Do not default to dark mode, purple gradients, glassmorphism, huge hero headings, cards for everything, random icon styles, decorative motion, low-contrast text, fake charts, or fabricated testimonials.
