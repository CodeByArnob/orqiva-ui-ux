# Web Applications

Define global navigation, workspace/account context, page title, primary action, content region, optional context panel, and account/notification controls.

SaaS and dashboards prioritize task clarity, information hierarchy, status visibility, and scanning. Cards must represent meaningful groups. Tables, filters, charts, and controls need real semantics and states.

Developer tools need information density without sacrificing readability, keyboard navigation, clear selection, resizable panels where useful, and visible execution status.

Use semantic HTML, accessible components, responsive CSS, and existing framework conventions. Avoid div-only interactive controls. Ensure routing, forms, menus, and controls work.
