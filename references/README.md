# ORQIVA Reference Library

This directory contains modular reference manuals for AI coding agents and human designers executing tasks with ORQIVA UI/UX.

Load only the reference modules relevant to your specific task to preserve token budget and optimize prompt context.

---

## Catalog of Reference Modules

1. **[design-directions.md](design-directions.md)**: Taxonomy of visual styles (Trust-Led, Calm, Utilitarian, Data-Dense, Minimal Editorial, Commerce, Platform Native).
2. **[ux-architecture.md](ux-architecture.md)**: Information architecture, hierarchy, layout anatomy, navigation systems, density tiers.
3. **[visual-foundations.md](visual-foundations.md)**: 4pt/8pt spatial grid, typographic scales, semantic color tokens, elevation and shadows.
4. **[design-systems-and-implementation.md](design-systems-and-implementation.md)**: Token translation architectures for Web/Tailwind, Flutter, Jetpack Compose, and React Native.
5. **[responsive-design.md](responsive-design.md)**: Content-based breakpoints, reflow patterns, touch ergonomics, and container queries.
6. **[accessibility.md](accessibility.md)**: WCAG 2.2 AA standards, contrast requirements, keyboard focus traps, screen reader ARIA patterns, reduced motion.
7. **[interaction-patterns.md](interaction-patterns.md)**: Form validation lifecycles, micro-interactions, data table behaviors, modals vs drawers.
8. **[mobile-platforms.md](mobile-platforms.md)**: iOS HIG vs Android Material 3, Jetpack Compose, Flutter, React Native conventions.
9. **[web-applications.md](web-applications.md)**: Dense SaaS layouts, telemetry cards, data grids, multi-pane split workspaces.
10. **[websites-and-landing-pages.md](websites-and-landing-pages.md)**: Landing page narrative structure, hero hierarchy, Core Web Vitals, conversion mechanics.
11. **[quality-audit.md](quality-audit.md)**: 5-dimension heuristic audit protocol and issue severity matrix.
