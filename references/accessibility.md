# Accessibility

Use semantic/native controls, accessible names, associated labels, logical headings, visible keyboard focus, keyboard navigation, sufficient contrast, text resizing/zoom, reduced-motion support, and meaningful image alternatives.

Do not use color alone for status. Avoid hover-only essential actions and keyboard traps. Manage focus in dialogs and menus. Make dynamic feedback understandable to assistive technology.

Forms need explicit labels, format guidance, text-based errors, preserved input where possible, and announced important status changes.

Audit keyboard-only use, focus, contrast, labels, semantics, zoom/reflow, reduced motion, and screen-reader behavior when tools exist. Report exactly which checks were performed.
