# Visual and UX Quality Audit

Review product fit, journey clarity, hierarchy, visual consistency, typography, layout, responsiveness, accessibility, feedback, content, component reuse, and maintainability.

Severity: Critical blocks a primary task or creates unsafe ambiguity; High is a major navigation/responsive/accessibility/comprehension issue; Medium is noticeable friction; Low is cosmetic.

When browser/screenshot tools exist, capture key screens at agreed viewports and inspect actual rendered UI for overflow, clipping, alignment, spacing, typography, contrast, and states. Record viewport and tool.

If tools are unavailable, perform source-level review and state that visual inspection was not performed.

Report inspected surfaces, viewports, findings by severity, fixes, commands/tests, and remaining limitations. Scores are review aids, not objective proof.
