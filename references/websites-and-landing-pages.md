# Websites and Landing Pages

Identify audience, offer, visitor motivation, authentic proof, and desired action. Select sections based on the actual site purpose; do not blindly use a fixed template.

Possible sections: navigation, value proposition, product/service explanation, benefits, proof, features, use cases, pricing, FAQ, CTA, footer.

Never invent customer logos, testimonials, statistics, certifications, awards, prices, or performance claims. Use approved placeholders only when content is missing.

Use readable hierarchy, purposeful imagery, clear CTA, responsive navigation, semantic headings/links, useful metadata, and accessible content.
