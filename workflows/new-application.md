# New Application Workflow

1. Inspect repository, framework, platform, dependencies, and conventions.
2. Identify product purpose, audience, main jobs, and constraints.
3. Create a concise design brief.
4. Select and justify a direction using design-directions.md.
5. Map screens, navigation, and primary journey.
6. Define tokens and reusable components.
7. Design and implement the main task flow.
8. Add relevant empty/loading/error/success/disabled/permission states.
9. Check responsive/adaptive behavior and accessibility.
10. Run project checks and inspect rendered output when tools exist.
11. Report files, decisions, results, and gaps.

Validate the main journey before expanding to every screen.
