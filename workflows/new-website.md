# New Website Workflow

Inspect repository and stack. Identify audience, offer, authentic proof, primary conversion, and content. Never invent claims or testimonials. Choose a fitting visual direction, define sitemap and hierarchy, create tokens/components, implement responsive navigation and interactions, validate forms, semantics, keyboard access, contrast, and mobile reflow. Run lint/typecheck/tests/build and inspect rendered pages when tools exist. Report verified items and gaps. Avoid generic landing-page templates unless they fit the brief.
