# Workflow: New Website & Landing Page Design

Use this workflow when creating a high-converting, accessible marketing website, landing page, documentation site, or product portal.

---

## Step 1: Context & Narrative Definition
1. Inspect project goals: What is the core value proposition? Who is the visitor?
2. Gather authentic proof points: real capabilities, genuine technical differentiators, real benchmarks. Never invent fake testimonials or vanity metrics.
3. Choose a visual language from [references/design-directions.md](../references/design-directions.md) (e.g., Modern Minimal Editorial or Utilitarian Developer Tool).

---

## Step 2: Sectional Architecture
Structure the narrative flow logically:
1. **Header / Navbar**: Brand mark, anchor links, theme switcher, primary CTA ("Get Started" / "Install").
2. **Hero Section**:
   - Eyebrow category tag.
   - High-contrast, scannable headline (6–12 words).
   - Supporting value proposition subtitle.
   - Dual action button group + one-click copyable install snippet.
   - Real, authentic product preview / interactive screenshot.
3. **Capability Grid**: 3–4 key architectural pillars with clear functional headings and concise explanations.
4. **Interactive Feature Deep-Dive**: Live code snippets, interactive tabs, or side-by-side comparisons.
5. **Comparison Matrix**: Direct, honest comparison with existing alternatives.
6. **FAQ Accordion**: Address real customer questions regarding compatibility, pricing, and performance.
7. **Global Footer**: Comprehensive site navigation, GitHub repository link, license details, and status.

---

## Step 3: Visual Polish & Responsive Layout
1. Implement responsive reflow across mobile (390px), tablet (768px), and desktop (1280px+).
2. Ensure touch-friendly mobile navigation with clean hamburger or sheet disclosure.
3. Optimize Core Web Vitals: reserve aspect ratios for all images and interactive canvas blocks.

---

## Step 4: Verification & Acceptance
1. Validate semantic HTML structure (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
2. Run contrast checks across both dark and light modes.
3. Verify all external links point to valid URLs.
4. Check keyboard focus rings on all buttons, links, and accordion triggers.
