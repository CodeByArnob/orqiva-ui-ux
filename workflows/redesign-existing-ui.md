# Redesign Existing UI Workflow

Inspect screens, code, routes, journeys, and components. Identify what works and must remain. Find usability, visual, accessibility, and responsive issues. Prioritize by user impact. Change design direction only when justified. Improve shared tokens/components before one-off fixes. Implement in small steps, check behavior regressions, run tests/build, compare screenshots when possible, and report preserved behavior, changes, and risks. Do not rewrite everything merely to make it look different.
