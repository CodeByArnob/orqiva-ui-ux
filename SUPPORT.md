# Getting Support for ORQIVA UI/UX

We are committed to providing support for developers and teams using ORQIVA UI/UX with AI coding agents.

---

## Channels for Help

1. **Documentation Website**:
   Explore the complete offline and online documentation at `https://codebyarnob.github.io/orqiva-ui-ux/`.
2. **GitHub Discussions & Issues**:
   - For bug reports or broken installation scripts: [Open an Issue](https://github.com/CodeByArnob/orqiva-ui-ux/issues).
   - For design questions or sharing implementations: [GitHub Discussions](https://github.com/CodeByArnob/orqiva-ui-ux/discussions).
3. **Agent Skill Support**:
   - Make sure your Agent Skills CLI is up to date: `npm install -g skills@latest`.
   - Verify skill installation: `npx skills list`.

---

## Frequently Asked Questions

**Q: Can I use ORQIVA in commercial projects?**  
A: Yes! ORQIVA is released under the permissive MIT License. You are free to use it in personal, open-source, and commercial projects.

**Q: Does ORQIVA send my code to any cloud server?**  
A: No. ORQIVA is a local Agent Skill and reference system. It runs entirely on your local workstation without external tracking or telemetry.
