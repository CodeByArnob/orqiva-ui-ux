# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

ORQIVA UI/UX is an open-source Agent Skill and documentation ecosystem. We take security seriously.

If you believe you have discovered a security vulnerability in this project:

1. **Do not** disclose the vulnerability publicly in an open GitHub issue or public forum.
2. Please privately email the maintainers or report via GitHub Security Advisories at:
   `https://github.com/CodeByArnob/orqiva-ui-ux/security/advisories/new`
3. Include detailed steps to reproduce the issue, sample prompts or code, and your environment configuration.
4. We acknowledge receipt within 48 hours and work with you to coordinate a responsible patch and release.
